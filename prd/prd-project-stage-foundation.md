# PRD-01：项目与阶段基础

> 版本：v1.0 Draft  
> 日期：2026-08-07  
> 状态：待评审  
> 上游依赖：无

## 1. 概述

建立开发项目及其阶段骨架。用户从默认开发模板创建项目，按实际流程调整阶段，并通过主阶段与并行阶段表达项目当前推进方向。

## 2. 目标

- 用户能在 10 分钟内创建项目并启动首个阶段。
- 默认模板覆盖常见软件开发生命周期。
- 阶段顺序、状态和主阶段规则明确且可验证。
- 阶段结构变化可追溯。

## 3. 用户故事

### US-001：使用开发模板创建项目

**Description:** 作为项目负责人，我希望从默认开发模板创建项目，以便快速获得完整的开发阶段结构。

**Acceptance Criteria:**

- [ ] 创建页展示需求分析、技术设计、开发、测试和发布五个默认阶段。
- [ ] 用户可在创建前增加、删除、重命名和调整阶段顺序。
- [ ] 阶段名称不能为空，同一项目内不能重名。
- [ ] 项目必须至少保留一个阶段。
- [ ] 创建成功后进入项目阶段列表。
- [ ] 前后端自动化测试通过。
- [ ] 在浏览器中验证默认创建和自定义阶段创建。

### US-002：管理项目阶段

**Description:** 作为项目负责人，我希望调整项目阶段，以便开发流程符合项目实际情况。

**Acceptance Criteria:**

- [ ] 可新增、重命名和调整未完成阶段的顺序。
- [ ] 删除包含任务或交付物的阶段前展示影响范围并二次确认。
- [ ] 已完成阶段不能删除或调整顺序。
- [ ] 只有项目负责人可修改阶段结构。
- [ ] 每次结构变化生成项目活动记录。
- [ ] 在浏览器中验证新增、排序、删除限制和权限状态。

### US-003：启动阶段和指定主阶段

**Description:** 作为项目负责人，我希望启动阶段并指定主阶段，以便团队知道主要推进方向。

**Acceptance Criteria:**

- [ ] 未开始阶段可启动为主阶段或并行阶段。
- [ ] 首个启动的阶段自动成为主阶段。
- [ ] 指定新主阶段后，原主阶段保持原状态并转为并行阶段。
- [ ] 项目存在活动阶段时必须且只能有一个主阶段。
- [ ] 受阻或待验收阶段可以保持主阶段身份。
- [ ] 阶段启动和主阶段切换生成活动记录。
- [ ] 在浏览器中验证首次启动、并行启动和主阶段切换。

### US-004：查看阶段列表

**Description:** 作为项目成员，我希望查看所有阶段及状态，以便理解项目开发路径。

**Acceptance Criteria:**

- [ ] 列表展示阶段名称、顺序、负责人、状态和计划日期。
- [ ] 主阶段和并行阶段有明确文字标识。
- [ ] 已完成、当前和未开始阶段可被清晰区分。
- [ ] 点击阶段进入独立阶段工作台 URL。
- [ ] 无阶段和加载失败时显示明确反馈。
- [ ] 在桌面和窄屏浏览器中验证阶段列表。

## 4. 功能需求

- FR-1：系统必须提供包含五个默认阶段的开发模板。
- FR-2：系统必须允许创建项目时调整模板阶段。
- FR-3：系统必须为阶段保存名称、目标、顺序、负责人和计划日期。
- FR-4：系统必须拒绝同一项目内的重复阶段名称。
- FR-5：系统必须保存阶段的独立状态。
- FR-6：系统必须允许多个阶段并行处于活动状态。
- FR-7：系统必须在存在活动阶段时保存唯一主阶段。
- FR-8：系统必须限制已完成阶段的结构修改。
- FR-9：系统必须记录阶段结构和主阶段变化。

## 5. 页面与路由

- 项目创建：`/projects/new`
- 阶段列表：`/projects/:projectId/stages`
- 阶段工作台占位：`/projects/:projectId/stages/:stageId`

## 6. 非目标

- 不定义阶段任务的具体交互。
- 不实现任务依赖、阻塞、交付物或阶段验收。
- 不提供行业模板或用户自定义模板库。
- 不根据日期自动启动或完成阶段。

## 7. 技术考虑

- 新增项目阶段实体，并以 `stage_id` 作为后续任务归属键。
- `is_primary` 唯一性和阶段状态转换必须由后端保证。
- 实施前确定现有 Sprint 数据的清空或迁移策略。
- 数据迁移需提供迁移前后项目、阶段和任务数量校验。

## 8. 成功指标

- 默认项目创建成功率达到 99%。
- 创建并启动首个阶段的中位时间不超过 10 分钟。
- 数据库中活动项目出现多个主阶段的数量为 0。

## 9. 开放问题

- 现有 Sprint 演示数据清空还是迁移为阶段？
